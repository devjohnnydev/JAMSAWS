Amazon Redshift Spectrum allows you to run queries against exabytes of unstructured data in Amazon S3. It extends the analytic power of Amazon Redshift beyond data stored on local disks in your Redshift data warehouse.
Redshift Spectrum leverages Redshift's fast query processing and integrates with other services like Lake Formation. You can query open file formats like CSV, Parquet, JSON, etc stored in S3 without having to load the data into Redshift tables.
Redshift Spectrum benefits:

* Query unstructured data in S3 without loading or transforming data
* Massively parallel query execution using Redshift's Massively Parallel Processing (MPP) architecture 
* Consistent performance querying small or large data sets
* No ETL jobs needed to preprocess data for queries
